Автоэкспорт Pixso Design File (.pix)

Имя файла при сохранении .pix

Подстановки: {{date}} — дата и время, {{title}} — имя, которое предлагает Pixso (без .pix), {{raw}} — исходное имя файла целиком. Расширение .pix добавится само, если его нет в шаблоне.

По таймеру выполняется тот же сценарий, что и при нажатии кнопки экспорта на панели (меню → Export → Pixso Design File). Срабатывает только когда активна вкладка с редактором Pixso. Минимальный интервал — 1 минута (ограничение Chrome). При каждом срабатывании браузер может показывать диалог сохранения файла — это ожидаемо.
