# My Fair Pixso

Расширение для **Google Chrome** и совместимых браузеров (Chromium, Edge, Brave и т.д.), которое дополняет работу с онлайн-редактором **[Pixso](https://pixso.net)** на доменах `pixso.net`.

## Что это такое

**My Fair Pixso** — неофициальное расширение: оно встраивается в страницу Pixso и помогает:

- убрать из списка плагинов лишние закреплённые пункты (Enterprise plugins), которые обычно нельзя открепить штатными средствами;
- быстро вызывать экспорт файла проекта в формат **.pix** с верхней панели;
- по желанию **периодически** запускать тот же экспорт (автосохранение в файл по таймеру);
- при скачивании **.pix** подставлять **имя файла по шаблону** (дата, название и т.д.);
- в модалке **публикации библиотеки** предлагать **отсортированный по группам и алфавиту** список компонентов (после сканирования с прокруткой) и удобный вид строк.
Настройки хранятся локально в браузере; расширение не добавляет отдельную страницу настроек в Chrome — всё делается через **всплывающее окно** по клику на иконку.

## Функции


| Возможность                                                                                                | Описание                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Скрыть Enterprise plugins**                                                                              | Удаляет из списка My Plugins закреплённые служебные строки (диапазон классов `plugin-dropdown-li-*-user`). Можно отключить, если нужен исходный список. |
| **Кнопка сохранения на панели**                                                                            | Добавляет в верхнюю панель кнопку для запуска цепочки «Файл → Export → .pix». Можно отключить.                                                          |
| **Автосохранение в файл**                                                                                  | По таймеру (от 1 до 120 минут) на **активной** вкладке с Pixso запускается тот же сценарий экспорта.                                                    |
| **Шаблон имени файла**                                                                                     | Если включено переименование загрузок, скачиваемые **.pix** получают имя по шаблону с подстановками `{{date}}`, `{{title}}`, `{{raw}}`.                 |
| **Сортировка в панели публикации**                                                                          | В модалке публикации библиотеки — кнопка **«Нормально покажи»**: сканирование списка с прокруткой и оверлей с группами (Changes / Unchanged / Hide) и алфавитным порядком имён; чекбоксы синхронизируются с настоящим списком. Без отдельного переключателя в настройках. |
| Подробнее о том, как устроены скрипты и обмен данными, см. [doc/doc.md](doc/doc.md). |                                                                                                                                                         |


## Установка из GitHub

Расширение в каталоге Chrome Web Store может отсутствовать — тогда его ставят **вручную из исходников** (режим разработчика). Ниже — максимально простой вариант.

### 1. Скачать архив с GitHub

1. Откройте страницу репозитория в браузере (адрес вида `https://github.com/<владелец>/<репозиторий>`).
2. Нажмите зелёную кнопку **Code**.
3. Выберите **Download ZIP**.
4. Сохраните файл и **распакуйте** ZIP в удобную папку, например «Документы» → `MyFairPixso`.

Важно: после распаковки у вас должна быть **папка**, внутри которой лежат файлы `manifest.json`, `background.js`, папка `icons` и т.д. Если ZIP создал вложенную папку с тем же именем — откройте именно **внутреннюю** папку с `manifest.json`.

### 2. Не удаляйте папку после установки

Chrome будет читать файлы расширения **напрямую из этой папки**. Переносите или удаляйте её только осознанно; иначе расширение пропадёт или сломается.

## Подключение в Chrome и использование

### Включить режим разработчика и загрузить расширение

1. Откройте Chrome.
2. В адресной строке введите: `chrome://extensions` и нажмите Enter.
3. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Укажите **папку**, где лежит `manifest.json` (та, что вы распаковали из ZIP).

Если всё прошло успешно, в списке появится **My Fair Pixso**.

### Как пользоваться

1. Откройте **[pixso.net](https://pixso.net)** и войдите в аккаунт как обычно.
2. Откройте нужный файл в редакторе.
3. Нажмите на **иконку расширения** на панели Chrome (если иконки не видно — откройте меню «пазл» и закрепите расширение).
4. Во всплывающем окне включите или выключите нужные пункты и нажмите **«Сохранить»**. Окно закроется через короткое время; настройки сохраняются в браузере.
5. На странице Pixso при включённых опциях появятся **кнопка экспорта на панели** и/или **очистка списка плагинов**; при включённом автосохранении экспорт будет периодически запускаться на **активной** вкладке с Pixso.

Если экспорт через кнопку сработал не с первого раза, в подсказке на кнопке указано открыть вручную **меню файла → Export**, затем снова нажать кнопку — так заложено под возможные изменения меню.

### Обновление

Если вы клонировали репозиторий через Git и обновили файлы (`git pull`), откройте снова `chrome://extensions` и нажмите **кнопку обновления** (круговая стрелка) у этого расширения, либо **«Загрузить распакованное»** заново не нужно — достаточно обновления, если путь к папке не менялся.
